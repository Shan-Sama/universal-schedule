# Ảnh minh họa cho README

Lưu ảnh chụp hướng dẫn sử dụng trong thư mục này với tên:

```text
01-chon-du-lieu.png
02-matching-cot.png
03-xem-truoc-matching.png
04-chon-mon-va-lop.png
05-ket-qua-tkb.png
```

Sau đó chèn vào `README.md` bằng đường dẫn tương đối:

```markdown
![Bước 1 - Chọn dữ liệu](docs/images/01-chon-du-lieu.png)
```

Không dùng đường dẫn tuyệt đối như `C:\Users\...`, vì người xem GitHub không thể truy cập file trên máy của bạn.
